# Read Alongside website content

The app repository owns the canonical product facts and exact prepared App Store fields in `docs/marketing/product-content.json`. This directory mirrors that baseline and its rendered `app-store-en.txt`. Synchronize with the app repository’s `scripts/marketing/sync-product-content.py --website-root /absolute/path/to/landing-pages`; add `--check` to detect drift.

Landing and product details are at `/read-alongside/` and `#preview`; privacy and support use the URLs in the baseline. Page copy may be tailored to each placement but must agree with the current facts. The full approved positioning remains “Start small. Find your pace. Read with intention.”

Git/website publication does not edit App Store Connect, upload an app, prove production iCloud transfer, or establish native accessibility or App Review acceptance. Historical dated reviews describe their recorded state rather than current release approval.
